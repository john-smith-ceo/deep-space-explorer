# Deep Space Explorer

Процедурная космическая заставка: один самодостаточный HTML без зависимостей.
Открывается с диска двойным щелчком и работает без сети.

## Как собрать и выложить

```bash
python3 build.py          # склеивает src/ в deep-space.html
./deploy.sh               # то же плюс публикация
```

Публикация — `publish site deep-space deep-space.html` (Cloudflare R2, скилл
`deploy-website`). Ссылка постоянная:
https://pub-d15fbb0cc777497db9c83655787f2abc.r2.dev/deep-space

Репозиторий: https://github.com/john-smith-ceo/deep-space-explorer

## Правила, по которым тут всё разложено

| Каталог | Что кладём |
|---|---|
| `src/data/` | то, что **можно перечислить**: галактика, светила, Солнечная система, объекты |
| `src/settings/` | то, **чем это настраивается**: плотность звёзд, дальность прыжка, громкость |
| `src/core/` | ядро без знаний о мире: генератор с сидом, словарь языков, холст |
| `src/engine/` | то, что делает из данных картинку |
| `src/ui/` | интерфейс |
| `docs/` | `DATA.md` — как пополнять мир; `shots/` — снимки |
| `archive/` | заменённое, но не выброшенное |

**Модули нельзя подключить через `<script type="module">`** — по `file://`
браузер их блокирует политикой CORS. Отсюда сборка склейкой в одну IIFE;
порядок задан в `build.py`, настройки и данные идут первыми.

## Мир — это база

`buildGalaxy()` строит всю карту при запуске: координаты систем, светила,
состав планет, разложенные по правилам объекты. Движок **материализует**
запись, а не выдумывает систему заново. Новый объект добавляется записью в
`src/data/objects.js` — движок про него знать не должен. Подробности в
`docs/DATA.md`.

## Чего стоит опасаться

- **Headless Chrome врёт про производительность.** `performance.now()` внутри
  страницы виртуализирован и возвращает нули, а счётчик кадров за виртуальную
  секунду на одной сцене выдаёт от 7 до 40. Цифры fps отсюда — не измерение.
  Тот же виртуальный таймер трижды показывал сломанный прыжок, который на
  самом деле работал: проверять надо счётчиком кадров, а не таймером.
- **Рабочие файлы держать в проекте.** Каталог `/tmp` вычищается при
  перезагрузке; однажды так пропала ночь работы.
- **Приёмка рефакторинга — кадр.** Собранный файл обязан давать тот же снимок
  при том же сиде; расхождение выше сотых долей единицы яркости означает, что
  что-то потерялось.
- **Звук проверяется офлайн-рендером**, а не на слух: аудиовыхода в headless
  нет. Спектральный центроид и пик огибающей ловят и «винтовой» призвук, и
  лишний верх.

## Язык

Интерфейс английский по умолчанию, русский переключается в опциях (`O`).
Все подписи — ключами словаря `src/core/i18n.js`, включая единицы, названия
планет и разделители разрядов. Строка в коде вместо ключа означает
непереведённый интерфейс.
